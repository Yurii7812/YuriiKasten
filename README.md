# paper-pkm-app（紙PKM）

紙のPKM（ツェッテルカステン）をデジタルでやる、シンプルなデスクトップアプリ（Electron）。
方法: https://yurii7812.github.io/homepage/ja/paper-pkm/

## 起動
`npm install`（初回のみ）→ `./paper-pkm.sh`（アプリ一覧の「紙PKM」でも可）。試験は `npm test`。

## 画面
- 左のタブ: **デジタル** / **紙** / **Index**（グローバルIndex とトピックIndex の一覧）。検索結果はまとめて出る
- 検索の順: **Index（キーワード）→ トピックIndex → ノート**
- ノートの上: `並列`（1a→1b）`分岐`（1a→1a1）`トピックIndex`
- デジタルは作った日時（`2026-10-10 11:12`、変えられない）。紙は日付なし、画像の横に「テキスト化」を書く
- 📷 スキャン取り込み: 1枚ずつ紙のIDを付ける（Enter 決定、Tab 前のID）

## リンク（書くとその場でリンクになり、クリックで飛ぶ）
| 書き方 | 意味 |
|---|---|
| `:1a` | 1a へ続く |
| `1a:` | 1a 全体 |
| `1a(1)` `:1a(1)` `1a(1):` | 1a の (1) の位置へ |
| `(1)` | 引用の目印（赤くなるだけ） |
| `(1):` `:(1)` | 同じノートの (1) の位置へ |

デジタルのリンクはデジタルへ、紙の中のリンクは紙へ（ID は別々）。

## トピックIndex
1行に `キーワード ID ID …`（ID がリンクになる）。`★ 名前` で別のトピックIndexへ。
編集はデジタル欄と紙欄に分けて書き、表示はキーワードごとにまとめる。

## 保存（Brave の Markdown Viewer でも全部たどれる）
保存先は普通のフォルダ（初期値 `~/PaperPKM`、右上 📁 で変更）。**`Index.md` を開けばリンクだけで全部に届く。**
- `Index.md` … キーワード → ID（あいうえお順）、トピックIndex 一覧
- `デジタル.md` / `紙.md` … ID の木（紙は先頭の番号ごと）
- `digital/<ID>.md`、`paper/<ID>.md` + `<ID>.jpg`、`topic/<名前>.md`
- 各ノートに 日付・キーワード・上/前/次/下・トピックIndex へのリンク
- アプリで書いた `:1a` などはファイルでは本物のリンク（`[:1a](1a.md)`）になり、読み込むと元に戻る
