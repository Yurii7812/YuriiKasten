# paper-pkm-app

紙のPKM（ツェッテルカステン）をデジタルでやる、すごくシンプルなアプリ。`index.html` をブラウザで開くだけ（サーバー不要）。

- 方法: https://yurii7812.github.io/homepage/ja/paper-pkm/
- ID: `1` → 広げる `1a`,`1b` → 深掘り `1a1`、自然順に並ぶ（Gnosis の `\F` と同じ考え方）
- 検索: ID・本文・キーワードを一度に絞り込み（キーワードが紙のIndex代わり）
- スキャン取り込み: 画像を選ぶ → 1枚ずつ表示。次のIDを自動提案（直前の `広げる`）、Enter で決定、Tab で前のIDを入れる
- リンク: 本文に `:7a1`（続き）`7a(1)`（引用）`7a:`（全体）と書くと、リンク先・被リンクが出る
- 保存: ブラウザ内（IndexedDB）。「書き出し／読み込み」でJSONバックアップ
