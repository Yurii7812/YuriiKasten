# paper-pkm-app（紙PKM）

紙のPKM（ツェッテルカステン）をデジタルでやる、すごくシンプルなデスクトップアプリ（Electron）。
方法: https://yurii7812.github.io/homepage/ja/paper-pkm/

## 起動
- `npm install`（初回のみ）→ `./paper-pkm.sh`（または `npm start`、アプリ一覧の「紙PKM」）

## 保存
ノートの保存先は普通のフォルダ（初期値 `~/PaperPKM`、右上の 📁 で変更）。
- `<ID>.md` … 先頭に `date` と `keywords`、あとは本文
- `<ID>.jpg` … スキャン画像（同じ ID）。画像だけのファイルも読む
- 削除は `.trash/` へ移動

## 機能
- ID: `1` → 広げる `1a`,`1b` → 深掘り `1a1`（自然順に並ぶ。Gnosis の `\F` と同じ考え方）
- 検索: ID・本文・キーワードを一度に絞り込み（キーワードが紙のグローバル Index 代わり）
- スキャン取り込み: 画像を選ぶ → 1枚ずつ表示、次のIDを自動提案、Enter で決定、Tab で前のID
- リンク: 本文の `:7a1`（続き）`7a(1)`（引用）`7a:`（全体）→ リンク先・被リンクを表示
